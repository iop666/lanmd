# mdlive

单用户局域网 Markdown 双向同步工具：在 Windows 上跑一个本地服务，把一个 Markdown 目录（vault）暴露给手机和 Windows 浏览器。手机浏览/编辑/自动保存，Windows 端用 VS Code / Obsidian 改文件后手机 **1 秒级自动刷新**。

同步机制只有两个：**版本号校验（PUT 冲突检测）+ SSE 单向广播**。没有任何协同编辑技术，磁盘是唯一真相源。

## 一键启动（Windows）

双击项目根目录的 **`start.bat`**：

- 首次运行自动安装依赖、自动构建，之后直接启动
- 服务在**最小化的后台窗口**运行（任务栏里的 "mdlive-server"），启动脚本窗口自动退出并打开浏览器
- 关闭服务：关掉那个最小化窗口，或双击 **`stop.bat`**
- 再次双击 start.bat 不会重复启动（检测到服务在跑就只开浏览器）

**首次使用**：浏览器打开 `http://localhost:8787` 后，页面会要求**设置配对码**（中文/英文均可）。设置完成会弹出连接信息：局域网地址 + 二维码（**二维码里已含配对码**，手机扫码直接连）。以后想再看连接信息，点侧栏底部的「连接信息 / 配对码」。

## 配对码与认证

- 配对码保存在 `config.json` 的 `token` 字段；忘了就删除该字段（或整个 config.json）重启，重新设置
- 手机连接：扫二维码，或打开地址后输入配对码
- 环境变量 `MDLIVE_TOKEN` 可强制指定（此时页面设置被禁用）

## 界面功能

- **右上角图标**：⏱ 倒计时暂存库（红点=有内容）、新建文件、新建文件夹、上传 .md 文件、导入本地文件夹、复制 Markdown 源码、复制纯文本。窄屏自动收纳进 ☰ 菜单
- **新建/上传位置**：始终落在**当前打开文件所在目录**（未打开文件时为根目录）；文件树中长按/右键目录也可在指定目录新建
- **上传**：Windows 选 `.md` 文件或多选；「导入文件夹」保留目录结构；安卓手机用「上传 .md 文件」从文件管理器选取。重名文件以导入内容为准
- **复制**：一键复制 Markdown 源码，或一键复制渲染后的纯文字（局域网 http 下自动用兼容方式写入剪贴板）
- **倒计时暂存库**：6 个独立槽位（1小时×2、30分钟×2、10分钟×2）。贴入内容或文件后开始倒计时，**到期自动删除**；在**任何一端**编辑保存都会刷新倒计时；顶栏 ⏱ 打开面板，倒计时逐秒可见，最后 1 分钟变红
- **文件管理**：长按/右键文件可重命名（自动补 .md 后缀）、删除；新建文件不带后缀会自动补 `.md`

## 配置

`config.json`（首次启动自动生成，参照 `config.example.json`）：

```json
{
  "vault": "D:/Notes",
  "port": 8787,
  "token": "配对码，空=待设置",
  "ignore": [".git", ".obsidian", "node_modules", ".trash"]
}
```

环境变量优先级更高：`MDLIVE_VAULT` / `MDLIVE_PORT` / `MDLIVE_TOKEN`（设置 `MDLIVE_VAULT` 时为无文件模式，不读写 config.json）。

## 开发模式

```bash
npm run dev
```

同时启动服务端（tsx watch，端口 8787）和 Vite 前端（http://localhost:5173，/api 自动代理）。

## 常见问题

**手机打不开地址？**
- 首次启动 Windows 防火墙可能弹窗，勾选「专用网络」允许 Node.js
- 手动放行：`netsh advfirewall firewall add rule name="mdlive" dir=in action=allow protocol=TCP localport=8787`
- 确认手机和电脑在同一 WiFi / 热点；公司网络常开 AP 隔离，可用手机热点验证

**忘了配对码？**
打开 `config.json` 查看 `token` 字段，或删除它重启重新设置。

**浏览器提示不安全 / 剪贴板不能用？**
本服务是纯 HTTP 明文（局域网内、配对码保护），属非安全上下文，复制功能已内置兼容方案。不要把端口暴露到公网；需要公网请套 VPN/Tailscale。

**Obsidian 库可以直接当 vault 吗？**
可以。`.obsidian` 目录默认在 ignore 列表，不会被监听或展示。

## 已知限制

- 局域网明文 HTTP（配对码保护），勿暴露公网；需要公网请套 VPN/Tailscale
- 倒计时暂存库到期即删（不进回收站），扫描周期 15 秒
- 非法 UTF-8（如 GBK）文件以替换字符显示，保存会转为 UTF-8
- 网络盘/UNC 路径的文件监听不可靠，vault 建议放本地磁盘
